# Git & Assets Hygiene Rules

## 1. Мета-файлы Unity
* Каждый файл или папка внутри `Assets/` ОБЯЗАНЫ иметь парный файл `.meta`.
* Ни при каких обстоятельствах не ломайте GUID существующих мета-файлов при перемещении ассетов.

## 2. Формат коммитов
* Коммиты пишутся в Conventional Commits формате: `feat:`, `fix:`, `refactor:`, `chore:`, `style:`, `docs:`.
* Перед коммитом код должен успешно проходить проверку `scripts/pre-commit-lint.sh`.
