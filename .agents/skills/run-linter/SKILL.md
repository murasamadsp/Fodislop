# Linter Validation Skill (Проверка кода)

Используйте этот навык перед созданием коммитов или завершением задачи для полной валидации кода.

## Порядок проверки
1. Выполните проверку локальных застейдженных файлов:
   ```bash
   ./scripts/pre-commit-lint.sh
   ```
2. Для глубокой проверки всей кодовой базы запустите в режиме CI:
   ```bash
   CI=true ./scripts/pre-commit-lint.sh
   ```
3. Все выявленные предупреждения StyleCop (`SA...`) и Roslynator (`RCS...`) должны быть исправлены до создания коммита.
