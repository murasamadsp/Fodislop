# Map Build Skill (Конвертация карт)

Используйте эту инструкцию при необходимости запекания или конвертации карт мира Fodinae в формат `.mapb`.

## Процесс конвертации
1. Проверьте наличие входных сырых данных тайлов (`cells`) и дорог (`road`).
2. Используйте инструмент `MapbConverter.cs` в редакторе Unity (меню `Fodinae -> Convert Map`).
3. Сгенерированный бинарный файл карты переместите в `Assets/StreamingAssets/WorldMaps/*.mapb`.
4. Убедитесь, что `MapManager` подхватывает запеченную карту при автономном запуске без сервера.
