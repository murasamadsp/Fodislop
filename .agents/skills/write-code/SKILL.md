# Write Code Skill (Стандарт написания C# кода)

Используйте этот навык при генерации, модификации или рефакторинге C# кода в проекте Fodinae.

## Чек-лист написания кода

### 1. Объявление типов и namespaces
- [ ] Обычный C# класс/структура? Используйте `namespace Fodinae.Domain;` (file-scoped).
- [ ] `MonoBehaviour` или `ScriptableObject`? Используйте `namespace Fodinae.Domain { ... }` (блочный namespace).
- [ ] Структура данных? Используйте `readonly record struct` и первичный конструктор `(int X, int Y)`.

### 2. Форматирование и скобки
- [ ] Открывающая фигурная скобка `{` ВСЕГДА на новой строке.
- [ ] Блоки `if`, `else`, `foreach` ВСЕГДА обернуты в фигурные скобки `{}`.
- [ ] После закрывающей скобки `}` стоит пустая строка (SA1513).
- [ ] В многострочных инициализаторах стоит закрывающая запятая `,` (SA1413).
- [ ] Отсутствуют неиспользуемые переменные и поля (IDE0051, S1481).

### 3. Зависимости и Unity API
- [ ] Зависимости запрашиваются через VContainer `[Inject]` или интерфейсы (`IMapDataProvider`, `IAudioSystem`), без обращения к старым `.Instance`.
- [ ] Никаких вызовов `GetComponent` / `Find` в `Update()`.
- [ ] Отсутствуют пустые блоки `catch {}`.

### 4. Проверка качества
По завершении изменений всегда запускайте линтер:
```bash
./scripts/pre-commit-lint.sh
```
