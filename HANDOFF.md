## Грабли инструментов (сэкономит время)

- **zsh не разбивает подстановку по словам.** `for f in $files` передаёт весь список одним аргументом. Использовать `while IFS= read -r`.
- **`.meta` переименовывать вместе с файлом**, иначе Unity потеряет GUID и все ссылки из сцен. Для `MonoBehaviour` имя файла обязано совпадать с именем класса.
- **Регекс по именам полей задевает текст комментариев** — проверять после массовых замен.
- **Защищать протокольные токены** перед заменой: наивный `Pack` → `Building` превращает `Packet` в `Buildinget`.
