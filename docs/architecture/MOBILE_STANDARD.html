Мобильный стандарт

Как интерфейс, камера и ввод работают на телефонах, планшетах, раскладушках и флипах. Только альбомная ориентация, обе стороны.

Модель экрана

  • Одна точка привязки документа к экрану — UIScreen.Bind: масштаб панели, безопасная область, классы формы. Смена экрана посреди сессии (поворот на 180°, раскрытие раскладушки, сплит) ловится опросом и переприменяет всё сразу.
  • На мобильной платформе пиксель панели = dp (1/160 дюйма): ScreenShapeRules.PhysicalPanelScale. UIScale из настроек — множитель поверх dp (схема конфига 44 сбрасывает его к 1.0). Десктоп остаётся на опорных 1920×1080.
  • Безопасная область — отступы корня документа (UISafeArea), считаются от размера панели, а не корня, и пишутся сравнением со стилем, а не с resolvedStyle.

Правила раскладки

  • Любая интерактивная цель — не меньше 44 dp по короткой стороне (общее правило для Button, Toggle, TextField, DropdownField).
  • Всё интерактивное — внутри безопасной области; цели не перекрывают друг друга; текст помещается в коробку или обрезается многоточием намеренно.
  • Окна, где содержимое выше экрана, листаются (ScrollView): вход, онбординг, настройки, раскрытый инвентарь, список программ.
  • На Micro убираются задание, бонус, навыки, строки статуса; управление дроном, чат, меню и программатор остаются.
  • Поля ввода (чат, «Сказать») — вверху экрана: снизу их закрывает системная клавиатура.

Камера

Зум задаёт короткую сторону кадра (в альбоме — высоту); длинная растёт с соотношением сторон до 2:1 (CameraViewRules, MaximumVisibleAspect). На 20:9 и ультрашироком мониторе обзор по ширине не больше, чем на 2:1.

Платформа

  • Сборка (BuildScript): Android и iOS — LandscapeLeft+Right, iOS — Metal, iPhone+iPad, отложенные системные жесты у краёв. Development-сборка — вариант кода Checked (UNITY_ENABLE_CHECKS).
  • Частота кадров «без ограничения» на телефоне — частота экрана, а не 30; экран не гаснет в игре; предупреждение о памяти сбрасывает чанки на диск и декодированный кэш ассетов; кэш ассетов на iOS исключён из резервной копии iCloud.

Проверка

  • MobileLayoutPlayModeTests — настоящие сцены и контроллеры, подменён только экран; 17 экранов и состояний (вход, регистрация, онбординг, меню, HUD, инвентарь, чаты, карта, программатор: список, создание, редактор, пауза, настройки) на 9 устройствах. Состояния открываются кнопками HUD. Отчёт и PNG — Logs/Diagnostics/MobileLayout/.
  • TouchControlsPlayModeTests — пальцы через Input System и UI Toolkit: стик и «Копать» одновременно, поворот на месте, тап по миру вторым пальцем, тап по кнопке не уходит в мир, пинч.
  • EditMode: ScreenShapeRulesTests, MobileScreenContractTests, MapPinchGestureTests.
  • Особенность batch-прогона: без фокуса приложения Input System отбрасывает ввод, а UI Toolkit не читает устройства. Виртуальные клавиатура и тачскрин теста включают AllDeviceInputAlwaysGoesToGameView и IgnoreFocus; палец подаётся и в Input System, и в панель.
